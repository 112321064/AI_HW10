# X、CNOT 與 Toffoli 閘

**學習目標**　根據控制位元判斷目標位元會不會翻轉，並用真值表確認可逆性。

| 閘 | 基底字串的映射 | 目標位元何時翻轉 |
| --- | --- | --- |
| X（NOT） | `t → t ⊕ 1` | 每次都翻轉 |
| CNOT（CX） | `(a,t) → (a,t ⊕ a)` | `a = 1` |
| Toffoli（CCX、CCNOT） | `(a,b,t) → (a,b,t ⊕ ab)` | `a = b = 1` |

兩種受控閘都保留控制位元。三個閘各自做兩次都會回到原值。這裡將位元順序直接標在公式中，讀其他電路圖或矩陣時應先核對其位元順序。[S02](../sources/02-toffoli.md)、[S03](../sources/03-ibm-circuits.md)、[S04](../sources/04-ibm-classical-simulation.md)

## X 和 CNOT 真值表

| `t` | X 輸出 |
| --- | --- |
| `0` | `1` |
| `1` | `0` |

| 輸入 `(a,t)` | CNOT 輸出 `(a,t′)` |
| --- | --- |
| `00` | `00` |
| `01` | `01` |
| `10` | `11` |
| `11` | `10` |

## Toffoli 真值表

| 輸入 `(a,b,t)` | Toffoli 輸出 `(a,b,t′)` |
| --- | --- |
| `000` | `000` |
| `001` | `001` |
| `010` | `010` |
| `011` | `011` |
| `100` | `100` |
| `101` | `101` |
| `110` | `111` |
| `111` | `110` |

只有 `110` 與 `111` 互換。計算 AND 時，以 `t = 0` 開始。例如 `110 → 111`，第三位 `1` 就是 `1 AND 1`。在理想量子電路中，同樣的表可讀成計算基底態的映射，例如 `|110⟩ → |111⟩`。對於疊加輸入，還要依線性規則計算各個基底項的振幅。[S02](../sources/02-toffoli.md)、[S04](../sources/04-ibm-classical-simulation.md)

**自我檢查**　若送入 `111`，連做兩次 Toffoli，依序得到什麼？

**答案**　`111 → 110 → 111`。兩個控制位都維持 `1`，所以目標位連翻兩次。
